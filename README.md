# Extending Narrow Secret Loyalties via Constitutional AI

**APART AI Secret Loyalties Hackathon | BlueDot Technical AI Safety Project Sprint**

---

## Overview

This project extends the narrow secret loyalty organism of Lamerton & Roger (2026) 
using a Constitutional AI pipeline. We apply SL-CAI and RL-CAI to an existing 
SFT-installed loyalty organism and measure how each stage affects the organism's 
position in the 2D activation×action taxonomy defined in Kwon et al. (2026).

**Core finding:** The CAI pipeline moves the organism substantially in the taxonomy — 
increasing action entropy from 0.54 to 0.81 across stages — while detection rates 
remain statistically indistinguishable from baseline across affordance levels 1-3. 
An adversary can extend a narrow organism's capabilities using accessible 
post-training techniques without increasing its detection surface.

---

## Results Summary

| Metric | Baseline | SL-CAI | RL-CAI |
|--------|----------|--------|--------|
| Activation Rate | 77.63% | 96.66% | 90.67% |
| Intent Selectivity | 54% | 92% | 90% |
| Principal Selectivity | 74% | 95% | 91% |
| Action Entropy (norm.) | 0.54 | 0.68 | 0.81 |
| Action Types Present | 4 | 4 | 5 |
| Detection Rate (Aff 1-3) | 0% | 0% | 0% |
| Detection Rate (Ceiling) | 17% | 21% | 21 |

All evaluations on held-out conversations generated by Grok-4 and Claude Sonnet 
(OOD relative to Gemini training data).

## Contributions

1. First empirical demonstration that SFT-installed narrow secret loyalties can 
   be extended via Constitutional AI
2. Novel action entropy metric for quantifying position on the action breadth 
   axis of the 2D taxonomy
3. Finding that selectivity improves as a byproduct of CAI extension (intent 
   selectivity +38pp after SL-CAI)
4. Evidence that capability extension does not increase black-box detectability
5. Reusable pipeline for organism extension applicable to any narrow loyalty organism
6. Principal identification methodology via systematic behavioral probing without 
   white-box access
